# DM返信テンプレート — BIRDIE HOUSE

> 使い方: 届いたDMのスクショをClaudeに送る → Claudeが下の型で返信案を作る → あたるさんが確認して送信。
> 空席は、返信する前に必ずお店に確認する。

## 1. 予約の受付（まず必要な情報を聞く）
```
メッセージありがとうございます！BIRDIE HOUSEです🐓
ご予約承ります。以下を教えていただけますか？

・ご希望の日にち
・お時間（17:00〜21:30の間でご入店）
・人数
・お名前
・お電話番号

確認してすぐにご連絡いたします。
```

## 2. 予約の確定
```
〇〇様
ご予約ありがとうございます！以下の内容で承りました。

📅 〇月〇日（〇）〇〇:〇〇〜
👥 〇名様（カウンター／個室）

【ご案内】
・お一人様につき、お任せ焼鳥のセット（¥4,400税込）をご注文いただいております
・お席は2時間制です
・ご変更やキャンセルはDMかお電話でご連絡ください

当日お会いできるのを楽しみにしております。
BIRDIE HOUSE
```

## 3. 満席のとき
```
〇〇様
ご連絡ありがとうございます。
あいにく〇月〇日〇〇:〇〇は満席となっております。申し訳ございません。

〇〇:〇〇以降、または〇月〇日でしたらご案内できます。
いかがでしょうか？
```

## 4. 定休日を指定されたとき
```
〇〇様
ご連絡ありがとうございます。
〇月〇日は定休日をいただいております。申し訳ございません。

定休日は毎週木曜日です（12月は1・3・8・17・24・31日がお休み）。
別の日でご都合はいかがでしょうか？
```

## 5. 5名以上
```
〇〇様
ご連絡ありがとうございます。
当店はカウンター12席と、4名様までの個室1室のお店です。
〇名様の場合、〇〇のかたちでご案内できます。（※お店に確認して記入）
```

## 6. よくある質問
- **料金は？** → お一人様、お任せ焼鳥のセット¥4,400（税込）をご注文いただいています。焼鳥は約75分、16本ほどを「ストップ」とおっしゃるまで1本ずつお出しします。箸休め・〆・デザート付き。アラカルトとドリンクは別料金で、ワンドリンク制です。
- **一人でも大丈夫？** → 大歓迎です。カウンター12席ございます。
- **子連れは？** → お子様連れも歓迎です。お子様も大人と同じセットをご注文いただく場合にご利用いただけます。
- **当日予約・飛び込みは？** → 歓迎です。空席はお電話かDMでお問い合わせください。
