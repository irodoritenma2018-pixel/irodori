# irodori — SNS運用代行

飲食店向けSNS（主にInstagram）運用代行の作業リポジトリ。

## 構成
```
clients/<店舗名>/      クライアントごとの運用資料
  00_hearing.md        ヒアリングシート（初回に店舗へ確認）
  01_audit.md          アカウント現状分析
  02_strategy.md       運用方針（ターゲット・投稿の柱・プロフィール）
  03_calendar-YYYY-MM.md  月間投稿カレンダー＋キャプション案
  04_kpi.md            数値記録（週次・月次）
templates/             新規クライアント用のひな形
```

## 運用フロー（1クライアントあたり）
1. ヒアリング（`templates/hearing.md` をコピー）
2. 現状分析 → 運用方針を店舗と合意
3. 月間カレンダー作成 → 店舗確認 → 撮影・制作 → 投稿
4. 毎週月曜に数値記録、月末に月次レポート（`templates/monthly-report.md`）
